Panduan: Simpan jurnal di Supabase milik sendiri
  1. Buat proyek baru di Supabase Dashboard khusus untuk jurnal ini.
  2. Buka SQL Editor, buat query baru, lalu jalankan SQL di bawah untuk membuat tabel jurnal dan izinnya.
  3. Di Project Settings → API, salin Project URL dan anon / publishable key. Jangan gunakan atau membagikan service_role key.
  4. Klik tombol Supabase di atas, masukkan URL dan key tersebut, lalu simpan. Pengaturan disimpan di browser ini dan tidak ditanam di kode halaman. Data contoh demo tidak akan diunggah; setelah tersambung, halaman menampilkan isi tabel Anda.
create table if not exists public.trading_journal (
    id bigint generated by default as identity primary key,
    trade_date timestamptz not null default now(),
    symbol text not null,
    action text not null check (action in ('LONG', 'SHORT')),
    status text not null check (status in ('WIN', 'LOSS', 'BEP')),
    pnl_usd numeric not null,
    notes text not null default ''
);

alter table public.trading_journal enable row level security;

drop policy if exists "Allow anon journal access" on public.trading_journal;
create policy "Allow anon journal access"
    on public.trading_journal
    for all
    to anon
    using (true)
    with check (true);

grant select, insert, delete on public.trading_journal to anon;
grant usage, select on sequence public.trading_journal_id_seq to anon;

Catatan privasi: kebijakan SQL ini mengizinkan akses anon ke tabel pada proyek tersebut. Gunakan proyek khusus jurnal, jangan masukkan data rahasia, dan jangan pernah memakai service_role key di browser. Siapa pun yang memperoleh URL dan anon key proyek dapat mengakses tabel ini.
